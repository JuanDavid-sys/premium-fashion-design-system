Modo Oscuro

Los tokens de color se adaptan automáticamente al esquema de color del sistema. Aplica la clase auto-theme al elemento raíz para activar el modo oscuro automático.

:root.auto-theme { --color-bg: #0A0A0A; --color-bg-secondary: #141414; --color-bg-tertiary: #1A1A1A; --color-text: #F5F5F5; --color-text-secondary: #A0A0A0; --color-border: #2A2A2A; --color-border-strong: #3A3A3A; }

Principios de Diseño de Color

Jerarquía Clara
Primario, secundario y terciario mantienen una jerarquía visual consistente en toda la interfaz.
Accesibilidad
Todos los colores de texto cumplen con WCAG 2.1 AA para contraste sobre fondos correspondientes.
Consistencia
El acento dorado se usa exclusivamente para interacciones y elementos de marca premium.
