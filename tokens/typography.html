Familias Tipográficas

Display — Cormorant Garamond
La elegancia en cada detalle
Serif editorial para títulos, titulares y elementos de marca. Transmite lujo y sofisticación.
--font-display: 'Cormorant Garamond', 'Georgia', serif;
Body — Inter
Claridad y legibilidad en cada palabra
Sans-serif geométrica optimizada para pantallas. Excelente legibilidad en todos los tamaños.
--font-body: 'Inter', 'Helvetica Neue', 'Arial', sans-serif;
Mono — JetBrains Mono
const token = 'valor';
Monoespaciada para código, valores de tokens y datos técnicos.
--font-mono: 'JetBrains Mono', 'Fira Code', monospace;
