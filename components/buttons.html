Usage Guidelines

When to use each variant

Primary

Use for the main action on a page. Only one primary button per section.

Secondary

Use for secondary actions or alongside a primary button.

Ghost

Use for low-emphasis actions like dismiss, skip, or cancel.

Accent

Use for premium or promotional CTAs to draw attention.

Danger

Use for destructive actions like delete or remove. Always confirm.

Outline

Use for tertiary actions or when visual weight needs to be balanced.

Link

Use for inline actions within text. Keeps reading flow natural.

Loading

Use during async operations. Prevents double-clicks.

Best practices

  • Use action-oriented labels: "Add to Cart", not "Submit"
  • Keep button labels concise — ideally 1-3 words
  • Maintain consistent sizing within a single context
  • Use icon buttons only when the icon is universally understood
  • Provide loading states for any action that takes >500ms
  • Minimum touch target: 44x44px for mobile devices
